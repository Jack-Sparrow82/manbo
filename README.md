# 崩坏：星穹铁道 · 世界观图鉴

课程作业网页。共 7 个页面，全部使用相对路径互链，可离线浏览，也可直接通过 GitHub Pages 发布。

## 页面结构

| 文件 | 内容 |
| --- | --- |
| `index.html` | 主页 · 章节导览（含指向全部 6 个分页面的链接） |
| `cosmos.html` | 宇宙本源 |
| `aeons.html` | 星神与命途（14 位官方星神画像） |
| `worlds.html` | 开拓航图 |
| `factions.html` | 群星势力（20 个势力及代表人物） |
| `characters.html` | 人物图鉴（54 位角色，可筛选、点击查看资料） |
| `glossary.html` | 术语辞典 |
| `styles.css` / `script.js` | 全站样式与交互（原生 HTML / CSS / JavaScript，无框架、无构建步骤） |
| `assets/` | 角色立绘、星神画像、命途图标、主视觉、站点图标 |

## 原创与素材说明

- 本站为课程作业原创整理：页面结构、版式与交互代码使用原生 HTML / CSS / JavaScript 从头编写，**未套用或使用从网上下载的现成网页、模板**。
- 角色立绘、星神画像、命途图标作为图片素材引用自 StarRailRes 开源素材库（游戏官方美术素材），仅用于课程作业展示，非商业用途。
- 世界观文字资料参考游戏内智库文本，以及 HoYoWiki、萌娘百科、BWIKI 等公开设定资料整理。
- 相关角色、商标与美术素材著作权归米哈游（HoYoverse）所有。本站为非官方粉丝向整理。

## 本地打开

双击 `index.html` 即可，全程无需联网。请保持文件夹结构完整，不要单独移动 `index.html` 或 `assets/`。
